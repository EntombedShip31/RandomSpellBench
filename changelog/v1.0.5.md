# RandomSpellBench v1.0.5 更新日志

> 小版本更新。两项新功能：勾选法术的批量生成卷轴 / 批量注入、随机法术书数量上限 12 → 20。
> 上限 20 的依据：Iron's Spells 原版 `/irons_spellbooks spellbook create <slots>` 指令的
> `slots` 参数范围即 1–20（反编译 1.20.1-3.16.3 确认为 `IntegerArgumentType.integer(1, 20)`），
> 法术轮盘可完整展示，这是原版指令 + 轮盘排版支持的最高上限。

---

## 1. 新增：勾选法术批量「生成卷轴 / 注入法术」

### 需求

点击主页面左侧法术的勾选框后，点击右侧「生成卷轴」「注入法术」能一键处理全部勾选的法术：

- 批量注入装备的法术不超过上限 **3 个**（单物品注入上限）；
- 装备本身的注入法术已经超过上限时，提示「注入法术超过装备上限」并整单拒绝；
- 批量生成卷轴单次最多 **12 张**；
- 生成多个卷轴不得造成卡顿。

### 实现

**触发规则（客户端 `SpellConfigScreen`）**

- 「生成卷轴 / 注入法术」改为按**勾选（启用）的法术集合**执行：
  - 勾选 1 个 = 原「单个生成 / 注入」行为（完全兼容旧操作习惯）；
  - 勾选多个 = 批量执行，按钮文案追加 `×N` 标出批量数量（卷轴按上限 12 截断显示）；
  - 全部取消勾选时兜底用当前选中的法术（保证按钮永不失效）。
- 按钮可用性从「需要选中法术」放宽为「有勾选或有选中即可」。

**网络层（防卡顿的关键）**

- 新增 `C2SBatchSpawnScrollPacket` / `C2SBatchImbuePacket`（追加在注册表末尾，不影响既有包 id）：
  勾选 N 个法术只发 **1 个**包，而不是逐个法术发 N 个包。
  逐个发包会让服务端做 N 次权限校验、N 次背包容器同步（`broadcastChanges`）、N 条 actionbar 播报，
  12 连发在客户端表现为明显卡顿与刷屏；批量包在服务端单次 `enqueueWork` 里顺序处理，
  只做一次背包同步、一次汇总播报。卷轴构建本身是轻量 NBT 操作，12 张一次性生成无感。
- 两个包都做了防伪造截断：卷轴 ≤ 12、注入 ≤ 16（配置上限余量）。

**批量卷轴（服务端 `TestManager.spawnScrolls`）**

- 上限 12 张（客户端截断并 actionbar 提示「勾选了 %s 个法术，单次最多生成 %s 张卷轴」，服务端再兜底截断）；
- 每张卷轴等级按该法术自己的「等级规则」随机（与单个生成一致）；
- 先全部预生成、任何一个失败整批取消，再统一入背包，放不下丢脚下并计入汇总播报。

**批量注入（服务端 `SpellImbueManager.imbueBatch`）**

- 装备位（主 / 副 / 头 / 胸 / 腿 / 脚）：
  - 受服务端配置 `maxSpellsPerItem`（默认 3）约束：能装几个装几个，装不下的跳过，
    汇总播报「已把 X 个法术注入到 Y（跳过 Z 个：已达单物品注入上限）」；
  - 物品本身的注入法术数**已经超过**上限（例如用指令塞了 5 个）→ 整单拒绝，
    提示「注入法术超过装备上限（该物品已有 X 个法术，上限 Y 个）」；
  - 恰好装满且无可替换 → 沿用「注入槽位已满」提示；
  - 已在装备上的重复法术原地替换等级，不占新槽位预算；
  - 全新物品的第一个法术仍走 ISS 官方 `createImbuedContainer` 入口，mustEquip / 轮盘语义与奥术铁砧一致。
- 书（饰品栏法术书）：容量上限跟随服务端 `maxSpells`（现为 20），跳过逻辑与装备位一致。

## 2. 调整：随机法术书数量上限 12 → 20

### 需求

随机生成法术书的数量上限原为 12，改为 Iron's Spells 原版用指令和快捷轮盘排版最高支持的上限。

### 实现

- 服务端配置 `random.maxSpells`：默认 12 → **20**，范围 1–20（对齐 ISS `spellbook create` 指令上限）；
  GUI「法术数量」滑条最大值跟随该配置，自动到 20。
- `random.defaultSpellCount` 范围同步放宽到 1–20。
- 配置迁移：服务端启动时把旧版本残留的 `maxSpells=12` 自动迁移到 20（v1.0.4 的 10→12 迁移保留，
  旧的 10 会直接迁到 20），日志输出 `Migrated randomspellbench-server.maxSpells from legacy default 12 to 20`。
- 法术书构建（`buildSpellbook`）与「注入到书」的容量判定均由该配置驱动，20 栏位无需额外改动。
