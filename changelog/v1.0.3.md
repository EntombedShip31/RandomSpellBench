# RandomSpellBench v1.0.3 更新日志

> 基于 v1.0.2（注入法术版本）的修复 / 精简版本。
> 构建产物已按需求复制到 `D:\PCL2\.minecraft\versions\1.20.1-Forge_47.4.10\mods`，并更新 GitHub 与本文档。

---

## 1. 删除功能：分配后「回满血量与饥饿、清除状态效果与 Iron's Spells 冷却」

### 现象 / 需求

该行为会打断 PVP 节奏，被判定为破坏公平性，整段删除。

### 操作

- `Config.Server`：删除配置项 `resetOnRandomize`（服务端 `[assignment]` 段不再生成该键）；
- `TestManager`：删除 `afterAssign` 里对它的调用，删除 `resetPlayerAfterAssign()`；
- 删除仅被该功能使用的 `compat/MagicCompat.java`（清 ISS 冷却 / 复唱的那层反射封装）。

## 2. 修改：分配结果播报固定开启，GUI 不再显示「聊天栏播报」选项

### 需求

聊天栏（actionbar）播报默认为开、且固定开启；随机法术测试台内不再显示该开关；清理不再需要的代码。

### 操作

- GUI：删除「聊天栏播报: 开/关」按钮整行（`chatResultButton`、`toggleChatResult()` 及其在
  `init / refreshDetail / reflowRightPanel` 的所有引用）；
- 服务端分配流程 `TestManager.afterAssign`：去掉 `isShowResultInChat()` 判断，每次分配结果都播报；
- 删除整个开关链路，含：
  - `PlayerSpellConfig` 的 `showResultInChat` 字段 / `KEY_CHAT_RESULT` / 存取方法及序列化；
  - `Config.Server.showResultInChat`（新玩家默认值不再需要）；
  - `C2STestActionPacket.Action.TOGGLE_CHAT` 及其服务端处理；
  - `/rsta chat` 子命令；
  - 语言键 `chat_result`、`on`、`off` 及 `/rsta` 用法串里的 `chat`。

## 3. 修改：注入目标新增「书」槽位（简写「书」），书满禁止写入

### 需求

主 / 副 / 头 / 胸 / 腿 / 脚之外再加一个「书」栏位：点「书」再点「注入法术」，
把选中法术写进自己 Curios 饰品栏的法术书；书的栏位满了就禁止写入。

### 操作

- `ImbueTarget` 新增 `SPELLBOOK(null, "spellbook")` 枚举项：
  - `getStack / setStack` 走 `EquipmentManager`（Curios `spellbook` 槽位），与其余六个原版装备槽并存；
  - GUI 槽位行随之变为 7 个按钮：`[主][副][头][胸][腿][脚][书]`；
  - 语言键：`target_spellbook` / `target_short_spellbook`（中：法术书（饰品栏）/ 书）。
- `SpellImbueManager.imbue()` 对 `SPELLBOOK` 走新的「写入法术书容器」分支：
  - 空白法术书自动初始化容器；已有法术保留，重复法术原地替换（一本书每个法术只占一格）；
  - 容量上限 = 服务端配置 `maxSpells`（法术书槽位上限，默认 12），
    active >= 上限即拒绝写入，并提示先「拆下卷轴」或重新随机分配腾出栏位；
  - 新增语言键 `imbue.book_done`（写入成功）与 `imbue_book_full`（书已满）。

## 4. 修改：「拆下卷轴」取代「清除」，并与上方槽位联动

### 需求

1. 「注入法术」右边换成已有的「拆下法术书卷轴」功能，两者横向平行；
2. 该按钮放在原「清除」的位置，可适当增宽，文案改为「拆下卷轴」；
3. 拆下功能与上方主 / 副 / 头 / 胸 / 腿 / 脚 / 书槽位联动：选「头」就能拆下头部位物品上的法术卷轴。

### 操作

- GUI「操作」区改为两行：
  - 行 1：`[主][副][头][胸][腿][脚][书]`（选中槽位有橙色描边）；
  - 行 2：`[注入法术] [拆下卷轴]`（横向平行，宽度按文本自适应）。
- 删除原整行「清除」按钮（`unimbueButton` / `clearImbue()`）与整行
  「拆下法术书卷轴」按钮（`extractButton` / `extractSpellbook()`），GUI 不再使用 `C2SExtractSpellsPacket`；
  （按 **V** 键与 `/rsta extract` 的「整本拆书」快捷方式保留不变。）
- 网络包 `C2SImbueSpellPacket` 新增 `Action.EXTRACT`，服务端转到新的
  `SpellImbueManager.extractAsScrolls(player, target)`：
  - 按选中槽位取物品，把容器里每个法术先预生成成 ISS 卷轴（任一失败整单取消），再改动物品；
  - 书 / 手持的法术书：拆掉指定法术、**书留在槽位**（栏位腾空，供继续注入 / 随机分配）；
  - 武器 / 盔甲：法术全部拆净时直接移除整个法术容器（等效忏悔石，不残留空容器）；
  - 卷轴优先进背包，放不下掉在脚下，成功后 actionbar 提示「已拆下 N 张法术卷轴」。
- 语言键：`btn_extract_target`（拆下卷轴 / Extract Scrolls）、`extract_no_item`，
  `imbue_bad_target` 的候选列表加入 `spellbook`。

## 需要验证的操作

1. 随机分配后：血量 / 饥饿 / 状态效果 / ISS 冷却**不再被改动**，分配结果在 actionbar 固定播报；
   界面与 `/rsta` 帮助里都不再有聊天播报开关。
2. 注入「书」：装备好法术书 → 点「书」→ 点「注入法术」，法术出现在书里（书内已有同名则替换）；
   书里写满（达到配置 `maxSpells`，默认 12 个）后再注入会提示已满、不写入。
3. 拆下卷轴联动：选「头」点「拆下卷轴」，把头盔上注入的法术拆成卷轴放进背包并清掉头盔注入；
   选「书」点「拆下卷轴」，把书里的法术拆成卷轴、书仍留在饰品栏槽位（栏位腾空后可再次注入）。
4. 「注入法术 / 拆下卷轴」为同一行并排按钮，与上方 7 个槽位按钮对位清晰。
