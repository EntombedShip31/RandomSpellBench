# RandomSpellBench v1.0.7 更新日志

> 围绕「便捷拿卷轴 + 测试」的小版本：新增法术无冷却开关与卷轴自动主手，
> 批量范围跟随搜索，修复书批量注入的空洞错位与 `/rsta scroll` 指令静默失效，
> 并按反馈去掉切换按钮激活态的外圈绿光。

---

## 1. 新增：「法术无冷却」测试开关

### 设计

- **入口**：右侧「操作」区段末尾新增切换按钮「法术无冷却（测试）」，与
  「每学派至少 1 个」「使用全局等级」同一套切换视觉（激活 = 绿字 + 绿色单线描边）；
  指令侧对等提供 `/rsta nocd`（切换，与 GUI 同一状态、同一持久化）。
- **状态存储**：`PlayerSpellConfig` 新增 `noCooldown` 布尔，走玩家配置 NBT 持久化
  （`NoCooldown` 字段），并随 `S2CSyncConfigPacket` 同步到客户端，跨存档保留。
- **服务端实现**：`ModEvents.onPlayerTick` 对开启的玩家每 10 tick（0.5 秒）清空一次
  ISS 冷却——入口与 ISS 自带 `ClearCooldownCommand` 完全相同
  （`MagicData.getPlayerMagicData(p).getPlayerCooldowns()` 的 `clearCooldowns()` +
  `syncToPlayer()`，全部位于 ISS api 包，免 Mixin / 反射）；关闭即恢复原版冷却，无残留。
  每 0.5 秒一次足够「冷却永远为零」的观感，避免逐 tick 空转。
- **边界**：只影响开关开启的玩家本人；权限复用 `PermissionHelper`（创造模式 / unlock）。
- **明确不做**：回满法力、回血饱食——创造模式本就不消耗，生存模式保持默认（按需求剔除）。

## 2. 新增：卷轴自动放主手

- 「生成卷轴」（单个与批量）默认**直接替换主手物品**：卷轴到手即可施放，
  原主手物品自动回背包（放不下丢脚下并计入掉落提示），测试连发免翻背包。
- 不想要该行为时可在客户端配置 `ui.autoScrollMainhand = false` 关闭（默认开启）。
- 实现：`C2SSpawnScrollPacket` / `C2SBatchSpawnScrollPacket` 增加 `mainhand` 标志位，
  服务端 `TestManager.giveScroll` 统一处理主手替换与回填；指令生成的卷轴保持入背包不变。

## 3. 新增：`/rsta scroll all [等级]` 指令批量

- 给勾选（启用）的法术各生成一张卷轴，单次上限 12 张（与 GUI 批量同一截断与提示）；
  带等级参数时整批使用该固定等级。不开 GUI 也能批量拿卷轴，补齐指令与 GUI 的对等性。

## 4. 修复：书批量注入的槽位空洞错位（v1.0.5 引入）

### 现象 / 根因

ISS 的 `removeSpellAtIndex` 只把槽位置空、不挪动后续法术——「拆下卷轴」后书里会留空洞。
单发注入用 `getNextAvailableIndex()` 优先填空洞；v1.0.5 的批量书注入却用
「已占用数」直接接末尾，跳过空洞扩容写入，导致同一本书两种路径写法不一致，
`getActiveSpellCount()` 与 `maxSpellCount` 关系被搅乱，后续容量判断可能提前报
「书已满」或漏判。

### 修复

`imbueBookBatch` 改为与单发完全一致的定位逻辑：优先 `getNextAvailableIndex()`，
返回值异常或不在已有占用范围内才接末尾；容量判定每轮以 `getActiveSpellCount()` 实时为准。

## 5. 修复：`/rsta scroll <法术>` 指令静默无效（历史遗留）

### 根因

旧实现把 `C2SSpawnScrollPacket`（注册为 PLAY_TO_SERVER）用 `sendToPlayer` 发回客户端、
指望客户端再回发——包到达客户端后 `getSender()` 为 null，handle 直接 return，
指令从未真正发过卷轴。

### 修复

指令改为服务端直接调用 `TestManager.spawnScroll`（同权限校验、同播报），
不再绕行网络包。

## 6. 修复 / 放宽：批量注入书的上限与提示

- `C2SBatchImbuePacket` 单批上限 16 → **20**，对齐书容量上限（勾选 17~20 个注入书
  不再被静默丢弃）；GUI 勾选超过 20 个时 actionbar 提示
  「勾选了 %s 个法术，单次最多注入 %s 个」（与卷轴 12 截断提示对齐）。

## 7. 优化：批量范围跟随搜索过滤

- 批量「生成卷轴 / 注入法术」的作用域改为**当前搜索可见 ∩ 勾选**的法术：
  搜索过滤出几个就测几个，「搜什么测什么」；搜索为空时退化为「全部勾选的法术」
  （与 v1.0.5 行为一致）。
- 左侧标题栏「法术池」右侧新增常驻小字角标「已勾选 N」（淡金色），
  承担原批量按钮 ×N 计数的信息量但不占按钮空间。

## 8. 调整：切换按钮激活态去掉外圈绿光

- 按反馈移除 v1.0.6 的三层辉光中两层外圈柔光（观感发虚），
  激活态保留**干净的绿色单线描边** + 绿字，三个切换按钮视觉统一。

## 9. 复核说明：卷轴固定等级无需修复

- 上一轮排查清单中的「固定等级模式下卷轴等级仍是随机」经复核**不成立**：
  `effectiveRange` 在固定等级模式下返回 min=max 的退化区间，`randomLevel` 恒等于固定等级，
  行为本就正确，未做改动。
