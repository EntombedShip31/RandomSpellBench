## 1. 修改：主界面标题栏显示版本号

### 需求

测试台最上方中间「随机法术测试台」后追加当前版本号（如 `1.0.4`），颜色要淡一点。

### 操作

- `SpellConfigScreen` 顶栏改为两段绘制：居中排版 = 标题 + 版本，标题保持原金色，
  版本号使用同一金色的半透明淡色（`0x66FFD699`）。
- 版本号运行时从 `ModList` 读取（`mod_id` 对应版本），只读一次并缓存；
  标题居中位置按「标题 + 版本」总宽度计算，保证整体视觉居中。

## 2. 修复：「拆下卷轴」无论选哪个部位都提示「全部锁定」

### 现象

v1.0.3 加入按槽位拆卷轴后，注入过法术的装备/武器点「拆下卷轴」总提示
「这本法术书的法术已经全部锁定，不能拆下」，功能不可用；且措辞把装备说成法术书。

### 根因

ISS 的「注入容器」（`createImbuedContainer`）写出的法术本身就是 `locked=true`
（对应 ISS 奥术铁砧的锁定语义）。旧实现把「可拆」与 `data.canRemove()` 绑死，
于是装备上**每一个**注入法术都被当成「锁定」跳过 → 扫描结果为空 → 走到了
「全部锁定」的错误分支。原来的「清除」之所以能用，是因为它不逐槽扫描、
直接移除整个容器，自然不受锁定影响。

### 修复

`SpellImbueManager.extractAsScrolls()` 调整锁定判定范围：
- **只对真正的法术书（ISpellbook）尊重「锁定」**：预设 / 独特法术书自带的锁定法术保留不拆；
- **武器 / 盔甲上的注入法术一律视为可拆**（它们本来就是注入上去的，锁定无保留意义），
  因此选任意部位都能正常把法术拆成卷轴并移除容器；
- 空结果时的错误文案改为面向目标槽位的通用提示（不再一概说「法术书」），
  只有目标确实是法术书且全部为锁定预设时才会出现“全部锁定”提示。

## 3. 修复：操作槽位的最后选择没有被记录

### 现象

上次选了「书」，退出后再打开测试台，槽位又回到默认「主手」。

### 操作

- 新增静态记忆 `rememberedImbueTarget`，随其余界面状态（选中法术 / 搜索 / 滚动 / 折叠）
  一起在界面 `removed()` 时保存；
- `init()` 开头恢复：有记录就应用（含 iss_ponder 思索返回重建界面的情况），
  无记录才保持默认主手。
