## 1. 修复：法术悬停预览（tooltip）判定不精准

### 现象

鼠标在法术行上左右移动时，法术详情时有时无：

- 图标、法术名开头一小段能弹出详情，再往右（长法术名的右半段、名称与等级之间的空白、等级文字上）
  详情就凭空消失；
- 拖住滚动条滚动列表时，详情会跟着乱闪。

### 根因

`SpellListWidget.getHovered()` 用一个魔法数把横向判定硬截断在「图标右侧 +50px」：

```java
// 修复前
int hoverLimit = getX() + ICON_X_OFF + ICON_W + 50;
if (mouseX >= hoverLimit) {
    return null;
}
```

这个阈值既覆盖不满整行（长名字右半段、等级列全掉出判定），也没有排除右侧滚动条轨道，
和渲染层整行 hover 高亮的范围（`mouseX < trackX() - 1`）根本不是同一块区域——
玩家看到的「高亮了」和「弹不弹详情」因此经常对不上。

### 修复

判定范围改为严格等于「该行实际绘制出来的矩形」：

- **纵向**：只认真正画出来的行 `[rowY, rowY + ROW_HEIGHT)`。被列表底边遮住的半行、
  最后一行下方的空白都不触发（原先这部分已处理，保留）；
- **横向**：整行除右侧滚动条轨道外都算，删掉 `+50` 魔法数，与 hover 高亮范围完全一致；
- **滚动中**：拖动滚动条期间不触发详情，避免滚动时 tooltip 乱闪。

## 2. 修复：选择「固定等级」后右侧文字错位

### 现象

点「固定等级」后，右侧那句「固定等级 LvN（所有法术）」没有跟着布局走，
被画到旧位置，正好压在下方「操作」区段的标题和按钮上。

### 根因

`drawSectionLabels()` 把这句提示画在 `sectionSpellY` 上：

```java
// 修复前
g.drawString(font, ..., rx + 66, sectionSpellY, 0xFFB08A55, false);
```

而固定等级模式下「选中法术」整段隐藏，`reflowRightPanel()` 会跳过该分支，
**`sectionSpellY` 这一轮根本不会被赋值**，一直保留上一次重排的旧值。
同时「操作」段因为上方少了一整段而整体上移，于是提示正好落在按钮上——即「字体错位」。

### 修复

- 新增 `fixedHintY`，由 `reflowRightPanel()` 在「选中法术」段隐藏时**单独占一行**，
  位置与原区段标题一致，从布局上保证它不可能与其它内容重叠；
- 新增 `showFixedHint()`（固定等级 + 有选中法术），布局与渲染共用同一判定，
  避免两边条件不一致又出现「文字画在没有占位的地方」；
- 渲染改用 `fixedHintY`，横向对齐到 `rx + 6`（与段标题文字同一缩进）。

## 3. 修复：法术注入（imbue）缺失服务端配置，项目无法编译

### 现象

`compileJava` 直接失败：

```
SpellImbueManager.java:97:  找不到符号 Config.SERVER.imbueMaxSpells
SpellImbueManager.java:143: 找不到符号 Config.SERVER.imbueAppend
SpellImbueManager.java:200: 找不到符号 Config.SERVER.imbueAllowAnyItem
```

### 修复

在 `Config.Server` 新增 `imbue` 配置段，键名与 `SpellImbueManager` 注释里写的保持一致：

| 键 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `imbue.maxSpells` | 整数 | `8`（范围 1–16） | 单件物品最多可注入几个法术 |
| `imbue.append` | 布尔 | `true` | 已注入的容器是追加还是整体替换 |
| `imbue.allowAnyItem` | 布尔 | `false` | 放开到任意物品（默认仅限剑 / 盔甲 / 饰品 / ISS 武器） |

## 4. 修复：法术行「选中」逻辑不一致

### 现象

点法术行左侧的小勾选框（小圆点）和点它右侧的行空白处，结果不是一回事：
点小圆点只切换「是否加入法术池」，点行空白处只改选中项。
于是「我明明点了这一行，生成卷轴却生成的是上一个法术」。

### 修复

- `SpellListWidget.mouseClicked()`：点击行内**任意位置**（含勾选框）都先执行真正的选中，
  只有落在勾选框矩形内（`CHECK_X_OFF + CHECK_W` = 12px）时再额外切换启用状态；
- `SpellConfigScreen`：新增唯一选中入口 `selectSpell()`，生成卷轴 / 思索 / 长按学习统一走它；
- `Delegate.isSelected()`：先比引用，再按 `getSpellId()` 兜底，避免法术池重建后高亮与选中错位。

## 5. 修复：滑块拖动 / 点击会改到别的控件

- 不再复用父类 `AbstractWidget` 的 `dragging` 字段（那套状态机只有 `AbstractSlider` 会正确收尾，
  自定义滑块用错后标志残留，会抢走后续所有拖动）；自持 `dragging`，并在 `mouseReleased` / `cancelDrag()` 收尾；
- 只有指针落在**轨道**上才开始拖动，不再走父类的 `onClick`；
- 外观改为「细长轨道 + 3×6 小把手」，不再画整行底衬和上下边框；
- 拖动中只本地更新，松手才 `commit()` 发一次网络包。

## 6. 修复：滚动面板内控件串位

- 按下时记录命中的子控件，拖动 / 释放只定向派发给它（此前广播给所有 children，
  任何残留 `dragging` 状态的控件都会抢先应答，表现为「拖下面的滑块却改了法术数量」）；
- 拖动 / 释放不再要求指针停在面板内，拖出面板或窗口外松手也能收尾；
- 新增 `clearDragging()` 兜底；每帧 `layout()` 同步内容高度，避免「内容溢出却滚不到底」。

## 7. 修复：右控制台布局错位、隐藏控件留下大片空白

- 「操作」区段从固定底部区域移回 `ScrollPanel`，按可见性流式重排，隐藏控件不占纵向空间；
- 各段标题 Y 由 `reflowRightPanel()` 直接写入 `sectionLevelY / sectionSpellY / sectionActionY / selectedNameY`，
  不再用「某控件 `getY()` - 偏移」反推；
- 滚动内容覆盖层用 `enableScissor` 严格裁剪在面板内，不再压到上方标题或下方固定底栏；
- 「状态」文字与「操作」标题同行显示。

## 8. 修复：搜索不支持拼音

- 新增 `PinyinUtil`，搜索键包含「中文原文 + 全拼连写 + 全拼空格 + 首字母」，
  「zhaohuanbeijixiong」「zhao huan」「zhbxj」均可命中「召唤北极熊」；法术 id 始终可搜；
- 语言文件同步更新占位文案：`搜索法术 / 拼音...`、`Search spells / pinyin...`。

## 9. 其它

- 移除已废弃的「[Shift=全部]」批量学习按钮文案（逻辑此前已删除，仅剩语言键）。
- 更新模组图标 `icon.png`。
- 版本号 `1.0.0` → `1.0.1`（`gradle.properties` 的 `mod_version`，`mods.toml` 由 `${mod_version}` 引用）。

1. **悬停预览**：鼠标从法术行最左（勾选框）一路移到最右（等级文字），详情全程稳定显示；
   移到行与行的边界、列表底部空白、滚动条上都不弹出；拖滚动条时不闪。

4. **选中一致性**：点小圆点 / 点行空白处 → 同一行高亮，「生成卷轴」得到该法术。
