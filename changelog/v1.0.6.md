# RandomSpellBench v1.0.6 更新日志

> v1.0.5 的 UI 打磨版本：三处界面优化 + 一处批量注入逻辑修复。

---

## 1. 调整：批量按钮去掉「×N」计数显示

### 需求

右下角「注入法术 ×130」「生成卷轴 ×12」的计数显示有问题，直接删掉计数显示，并复核批量功能本身的正确性。

### 操作

- `SpellConfigScreen.refreshDetail()` 移除「×N」文案拼接，按钮恢复为固定文案
  「注入法术 / 生成卷轴」（批量行为不变，仍在服务端受 12 张 / 单物品上限约束）。

### 复核结果（修复 1 个真 bug）

- **修复：覆盖模式（`appendToExisting=false`）下批量注入会写入多个法术。**
  该模式下单个注入的语义是「整件物品只保留一个法术」，但批量路径在 seed 第一个法术后
  继续按上限追加。现修复为：覆盖模式时 budget 置 0，第一个法术之后全部跳过，
  与单个注入语义一致（默认的追加模式不受影响）。
- 其余批量路径复核通过：卷轴批量 ≤12 截断、预生成失败整批取消、
  注入超上限报「注入法术超过装备上限」、恰好装满报「槽位已满」、
  重复法术原地替换不占预算、书按容量（20）裁决——均与 v1.0.5 设计一致。

## 2. 优化：切换按钮激活态去掉「[x]」前缀，改用绿色辉光描边

### 需求

「[x] 每学派至少 1 个」「[x] 使用全局等级」的勾选标记不够美观，改用高级的颜色和特效。

### 操作

- 文案：激活 = 绿字（与「范围随机」激活态同一套配色），未激活 = 灰字，不再拼接 `[x] / [ ]` 前缀。
- 特效：激活时在按钮四周绘制**三层绿色辉光描边**（外圈半透明柔光 → 内圈亮绿实线，
  `COLOR_TOGGLE_GLOW = 0x668FE86B` / `COLOR_TOGGLE_ON = 0xFF8FE86B`），
  模拟柔光溢出效果；渲染在 ScrollPanel 上方的 scissor 层，随滚动同步移动。
- 新增 `drawToggleHighlights()` / `drawGlowBorder()`，与「部位按钮」的橙色描边
  （`drawImbueTargetHighlight`）同一渲染管线。

## 3. 优化：右侧控制台移除滚动条

### 需求

右侧面板的竖向滚动条挡住了「拆下卷轴」等按钮，去掉滑块，用滚轮滑动即可。

### 操作

- `ScrollPanel` 移除滚动条绘制（`renderScrollbar` 整个删除）。
- 滚动能力保留：鼠标滚轮悬停在右侧面板**任意位置**即可滚动（无需瞄准滚动条），
  滚动范围 / 内容裁剪 / 拖拽转发逻辑不变；左侧法术列表的滚动条不受影响。
