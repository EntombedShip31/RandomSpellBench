# RandomSpellBench v1.0.8 更新日志

> 按测试反馈的回调与修复版本：移除 v1.0.7 的「法术无冷却」功能与 V 键快捷键，
> 切换按钮选中样式统一为橙色描边，并修复 `/rsta unlock` 状态死亡后丢失的问题。

---

## 1. 移除：「法术无冷却」功能（v1.0.7 引入）

### 原因

创造模式本身施法就不消耗法力、也无冷却等待，该开关没有实际使用场景（按反馈剔除）。

### 清理范围（全链路移除）

- GUI：删除右侧「操作」区段末尾的切换按钮及相关渲染分支；
- 指令：删除 `/rsta nocd` 及 usage 文案；
- 网络：删除 `C2SSetNoCooldownPacket` 及其注册；
- 数据：删除 `PlayerSpellConfig.noCooldown` 字段与 NBT 读写；
- 事件：删除 `ModEvents.onPlayerTick` 的周期清冷却逻辑。
- **协议版本 1.0 → 1.1**：v1.0.7 已发布的包 id（C2SSetNoCooldownPacket）在本版不复存在，
  强制两侧版本匹配，避免旧客户端向新服务端发送已删除的包 id 导致错解。
  （因此 1.0.7 与 1.0.8 不能互通，请两侧一同升级。）

## 2. 移除：「拆下法术书」V 键快捷键

- 删除 `ClientSetup.EXTRACT_SPELLS` 的注册与客户端按键处理；
- 整本拆法术书仍可用 `/rsta extract [hand|curio]` 指令完成，功能不受影响；
- 腾出的按键位不再占用，其余按键（F6/K 打开测试台）不变。

## 3. 调整：切换按钮选中样式统一为橙色描边

### 反馈

「范围随机 / 固定等级」的样式是对的；「每学派至少 1 个」「使用全局等级」
激活态的绿色外框不对——不要特别绿的发光外框，仿照注入部位按钮（如「主」）的橙色选中样式。

### 修改

- 激活态描边颜色从绿色（`0xFF8FE86B`）改为**主题橙**（`COLOR_ACCENT = 0xFFFF8C00`），
  与注入部位按钮的选中描边完全同款；
- 激活态绿字、未激活灰字的文案配色保持不变（与「范围随机 / 固定等级」一致）；
- 涉及「每学派至少 1 个」「使用全局等级」两个切换按钮（`drawToggleBorder`）。

## 4. 修复：`/rsta unlock` 状态死亡后丢失

### 根因

玩家死亡重生是**全新的 Player 实体**，`getPersistentData()` 不会自动带过去——
unlock 的解除状态（存在玩家配置 NBT 里）随旧实体一起消失，重生后恢复为「仅创造模式可用」。

### 修复

- `PlayerConfigStore` 新增 `copy(from, to)`；
- `ModEvents` 监听 `PlayerEvent.Clone`（`isWasDeath()` 时）把测试台配置整体复制到新实体——
  不只 unlock，**勾选、等级规则、随机配置**等也一并跨死亡保留。

## 5. 自查附带修复

- 删除 V 键后清理了 `ClientEvents` 中残留的 `NetworkHandler` / `C2SExtractSpellsPacket` 未用 import；
- 确认 `/rsta extract` 指令路径不受按键移除影响（`C2SExtractSpellsPacket` 的 `From.HAND/CURIO` 仍在用）。
